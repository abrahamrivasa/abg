# Calculadora anual de ISR para asalariados (México)

Aplicación web estática para estimar ISR anual con base en:

- Ingresos anuales brutos.
- Deducciones personales anuales.

## Uso local

```bash
python3 -m http.server 4173
```

Luego abre `http://localhost:4173`.

## Alcance

El cálculo es una estimación basada en tramos anuales de ISR y no reemplaza asesoría fiscal.
